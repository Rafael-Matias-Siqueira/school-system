# 📚 School Management System

Sistema de Gestão Escolar desenvolvido para facilitar o gerenciamento acadêmico de instituições de ensino.

O projeto nasceu com a ideia de recriar e modernizar um sistema escolar utilizado durante meus estudos, corrigindo problemas de usabilidade e implementando uma interface mais simples, organizada e intuitiva.

> **Status:** 🚧 Em desenvolvimento

---

# 🎯 Objetivo

Desenvolver uma plataforma capaz de auxiliar professores, coordenação, alunos e responsáveis no acompanhamento das atividades escolares, permitindo o gerenciamento de notas, disciplinas, turmas e boletins de forma prática e eficiente.
